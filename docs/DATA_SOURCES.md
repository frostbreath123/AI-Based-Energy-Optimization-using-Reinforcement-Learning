# Data sources and provenance

Generated by `python -m energyrl.data.manifest`. All real data are for **France**: market, PV and carbon for calendar year 2019, industrial load shapes from 2018 (aligned by weekday). Processed public data, derived data and synthetic data are labelled separately.

## Renewables.ninja hourly PV output (MERRA-2), 1 kWp reference system
- **Class:** processed public data
- **Publisher:** Renewables.ninja (Pfenninger & Staffell; Imperial College London / ETH Zurich)
- **URL:** https://www.renewables.ninja/api/data/pv
- **Retrieved:** 2026-10-27
- **Units:** kW per kWp
- **Resolution:** hourly (UTC)
- **Geography:** Paris, France (lat 48.85, lon 2.35), tilt 35 deg, south, losses 10%
- **License:** Renewables.ninja states CC BY-NC 4.0 (non-commercial, attribution); verify at https://www.renewables.ninja/about. Anonymous API access, no account created.
- **Preprocessing / notes:** Parsed from the JSON API response, clipped to [0,1] kW/kWp, converted from UTC to Europe/Paris local time.
- **Role in simulation:** Actual on-site PV generation = capacity factor x installed kWp x scenario scale.
- **Local files (data/raw):** pv_ninja_paris_2019.json

## ELMAS: hourly electrical load profiles of French industrial and tertiary sectors (18 clusters, 2018)
- **Class:** processed public data
- **Publisher:** Bellinguer, Girard, Bocquet, Chevalier (MINES Paris - PSL / Enedis); Scientific Data 10, 2023
- **URL:** https://doi.org/10.1038/s41597-023-02542-z (data: https://doi.org/10.6084/m9.figshare.23889780.v1)
- **Retrieved:** unknown (cached)
- **Units:** average energy per hour per cluster (normalised to mean 1 here: only the SHAPE is used)
- **Resolution:** hourly, one year (2018), averaged over 55,730 customers
- **Geography:** France (Enedis network)
- **License:** CC BY 4.0 (Figshare record)
- **Preprocessing / notes:** Decimal commas parsed; each cluster divided by its annual mean; timestamps shifted by 364 days so 2018 weekdays/seasons align with the 2019 calendar; clusters [1, 10] used for training scenarios, [14, 11] held out for an OOD family.
- **Role in simulation:** Shape of the plant's inflexible load (base_kw_mean x shape). Absolute plant size is an assumption.
- **Local files (data/raw):** Time_series_18_clusters.csv

## Day-ahead spot price, bidding zone FR
- **Class:** processed public data
- **Publisher:** Fraunhofer ISE Energy-Charts API; data from Bundesnetzagentur | SMARD.de
- **URL:** https://api.energy-charts.info/price?bzn=FR
- **Retrieved:** 2026-10-27
- **Units:** EUR/MWh (converted to EUR/kWh)
- **Resolution:** hourly
- **Geography:** France bidding zone
- **License:** CC BY 4.0 (stated in the API response: 'CC BY 4.0 from Bundesnetzagentur | SMARD.de')
- **Preprocessing / notes:** Resampled to hourly mean, /1000, local time. Negative prices kept in the spot series; the customer tariff is floored at 0.
- **Role in simulation:** Wholesale component of the tariff (tariff = spot x scale + network adder + levies).
- **Local files (data/raw):** prices_fr_2019.json

## Public net electricity generation by source, France
- **Class:** derived from public data + literature factors
- **Publisher:** Fraunhofer ISE Energy-Charts API (ENTSO-E based)
- **URL:** https://api.energy-charts.info/public_power?country=fr
- **Retrieved:** 2026-10-27
- **Units:** MW per source type
- **Resolution:** hourly/15 min, resampled to hourly mean
- **Geography:** France
- **License:** Energy-Charts states CC BY 4.0 for its data (the response carries no licence field; verify at https://www.energy-charts.info).
- **Preprocessing / notes:** Per-source MW averaged hourly; null/negative -> 0; carbon intensity = sum(generation x emission factor) / sum(generation). Imports/exports and pumped-storage charging excluded (production-based).
- **Role in simulation:** Time-varying grid carbon intensity (gCO2e/kWh); France is nuclear-dominated so the level is low (about 54 g/kWh mean).
- **Local files (data/raw):** public_power_fr_2019_01.json, public_power_fr_2019_02.json, public_power_fr_2019_03.json ...

## Emission factors per generation technology
- **Class:** literature constants
- **Publisher:** IPCC AR5 WGIII (2014) Annex III, Table A.III.2 (median lifecycle): coal 820, gas CCGT 490, biomass 230, geothermal 38, hydro 24, nuclear 12, solar PV utility 48, onshore wind 11, offshore wind 12 gCO2e/kWh
- **URL:** https://www.ipcc.ch/report/ar5/wg3/
- **Retrieved:** n/a
- **Units:** gCO2e/kWh
- **Resolution:** constant
- **Geography:** global medians
- **License:** IPCC reports: free for non-commercial use with citation
- **Preprocessing / notes:** Lignite (1000), oil (650), coal-derived gas (600), waste (400), others (500) are ANALYST ASSUMPTIONS (not IPCC values) - see config/default.yaml.
- **Role in simulation:** Convert the generation mix into carbon intensity.

## TURPE 7 HTA network tariff, variable energy component (grid of 1 Aug 2025)
- **Class:** published regulated tariff (transcribed by hand into config/default.yaml)
- **Publisher:** Commission de regulation de l'energie (CRE), deliberation no 2025-40 of 4 Feb 2025
- **URL:** https://www.cre.fr/fileadmin/Documents/Deliberations/2025/250204_2025-40_TURPE_7_HTA-BT.pdf
- **Retrieved:** 2026-10-28
- **Units:** c EUR/kWh for the five ranges PTE, HPH, HCH, HPE, HCE; options CU (short) and LU (long utilisation)
- **Resolution:** five time ranges (fixed peak Dec-Feb; high season Nov-Mar, low season Apr-Oct; full vs off-peak hours)
- **Geography:** France, medium-voltage (HTA) grid users
- **License:** Public regulatory document (CRE); cite the deliberation
- **Preprocessing / notes:** Values copied from the 'Grilles simplifiees de la composante de soutirage au 1er aout 2025' table (CU 5.85/4.31/2.03/1.03/0.71, LU 2.71/2.14/1.50/0.94/0.69 c/kWh). Off-peak placement A = 22-06 h and Sundays (CRE text); placement B = low-season off-peak 02-06 h + 11-15 h (derived from CRE Table 47 'hours to favour' 02-06 h and 11-17 h; 8 h/day). Exact fixed-peak hours 09-11 h and 18-20 h are an ASSUMPTION inside the CRE windows (08-12 h, 17-21 h). The 2026 +3.04 % indexation and the power (EUR/kW/yr) components are not applied, except that the CU power term 14.70 EUR/kW/yr/365 is used as the daily demand charge. Supply margin, accise and CTA (0.03 EUR/kWh) are assumed, not sourced.
- **Role in simulation:** Network part of the electricity price: gives the peak / intermediate / off-peak structure. NOTE: tariff year (2025-26) differs from the market data year (2019); the wholesale price is used as a level-shifting signal.
- **Local files (data/raw):** CRE_2025-40_TURPE7_HTA-BT.pdf

- **Class:** SYNTHETIC (generated)
- **Publisher:** this project
- **URL:** -
- **Retrieved:** n/a
- **Units:** kW, hours
- **Resolution:** hourly
- **Geography:** stylised manufacturing site
- **License:** project code

## Coherence and limitations of combining sources

- Everything real is French. PV is a Paris point (proxy for the national fleet), price and carbon are national, load shapes are from the French distribution network.
- ELMAS is 2018, market/PV/carbon are 2019. The load shape is shifted by 364 days so weekday and season align; year-specific weather effects on load are not matched to 2019 weather.
- ELMAS profiles are averages over many customers (anonymisation), so they are smoother than a single plant's load; only their shape is used.
- Renewables.ninja's anonymous API begins at 2019, which fixed the data year; its licence is non-commercial.
- Timestamps are aligned in UTC then converted to Europe/Paris local time; DST-transition days and incomplete days are dropped (360 of 365 days kept). Gaps up to 3 h are interpolated.
- The network tariff is the real TURPE 7 HTA grid (2025-26) combined with 2019 wholesale prices; the supply margin/taxes, jobs and plant size are synthetic.
- An earlier iteration used German 2023 data (PVGIS, Energy-Charts DE-LU); those files and results are archived under `data/archive_germany_2023/`, `results/archive_v2_germany_lookahead8/`.
